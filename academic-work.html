MetroMetrics - Web-Based Transit Analytics Platform

Group Capstone/Major Project | Advanced Data Analytics Course

Project Overview

Problem: Transit authorities lacked real-time or predictive data on train passenger crowding, leading to operational inefficiencies during peak hours and a degraded passenger experience.

Solution/My Role: As Lead Developer, I spearheaded the integration of the backend ML model (XGBoost) with the Django web framework. The final platform provides predictive hourly crowding forecasts and embeds interactive Google Looker dashboards for visualization.

Technical Stack & Links

  • Backend: Python (Django), XGBoost (Machine Learning), MySQL
  • Frontend/Visualization: HTML/CSS, Embedded Google Looker Studio

Barangay 756 Community Web Portal

Group Community Project | Information Systems Strategy Course

Project Overview

Problem: The local community required a central, accessible source of information for announcements, services, and regulatory forms, which was previously scattered and difficult to find.

Solution/My Role: Collaborated with the team under the Agile-Scrum methodology. My focus was on Information Architecture and Accessible UI Design, specifically structuring the navigation and content layout using Google Sites to ensure easy use by all residents.

Technical Stack & Links

  • Tools: Google Sites, Figma (for mockups), UI/UX Design Principles
  • Methodology: Agile-Scrum Sprints, Product Owner Feedback loops
