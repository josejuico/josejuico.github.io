Smart Trash Can with Touch-Free Lid Operation and Waste Level Indicator

Problem: In environments like healthcare facilities or public spaces, physical contact with trash bins poses sanitation risks. Standard bins lack accessibility features for individuals with mobility issues and offer no visibility into fill levels, leading to inefficient waste management.

Solution: I designed and built a fully functional prototype using the Arduino ecosystem. The system utilizes ultrasonic sensors to detect user proximity for touch-free lid operation (via servo motor) and continuously monitors internal waste volume. Real-time status updates and fill-level bar graphs are rendered on an LCD screen.

Technical Stack and Hardware

  • Microcontroller: Arduino Uno R3
  • Sensors and Actuators: HC-SR04 and HY-SRF05 (Ultrasonic), SG90 Servo Motor
  • Software: C++ (Arduino IDE), NewPing Library, LiquidCrystal_I2C Library
  • Skills: Circuit Design, Schematic Interpretation, Hardware-Software Integration

IoT-Based Pet Fan Control System Using PIR and Ultrasonic Sensors

Problem: Traditional mechanical timers lack adaptability, often wasting energy by running fans when pets aren't present. Outdoor pets in the Philippines require a cooling solution that is both responsive and energy-efficient.

Solution: I developed a smart fan system powered by an ESP32 microcontroller. It utilizes a dual-sensor logic: a PIR sensor detects initial motion, while an Ultrasonic sensor verifies sustained proximity to ensure the fan only runs when the pet is actually present. The system integrates with Firebase Realtime Database to allow remote control and timer configuration via a custom Android app.

Technical Stack and Hardware

  • Microcontroller: ESP32 (Wi-Fi enabled)
  • Cloud and Connectivity: Firebase Realtime Database (RTDB), Wi-Fi
  • Hardware: PIR Sensor (HC-SR501), Ultrasonic Sensor (HC-SR04), 5V Relay
  • Software: C++ (Arduino IDE), Android Application Development
