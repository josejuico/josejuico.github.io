Solo Development Projects and Hobbies

These activities demonstrate the application of my technical knowledge in a non-academic, community-driven context.

ROMdle Helper | Python and Data Handling

To support the Ragnarok Mobile gaming community, I built a dedicated "Wordle-solver" web application using Python and Flask. Recognizing that the game's daily puzzles rely on niche vocabulary, I created a database of game lore (monsters, items, and NPCs) and implemented search logic that helps users narrow down the correct word based on their current guesses and constraints.

Linux Kernel Driver Patch (RTL8852AU) | System Administration and Open Source

I engineered a patch for the Realtek RTL8852AU Wi-Fi driver to resolve compatibility issues with Ubuntu 24.04 LTS and the newer Linux Kernel 6.11. The project involved updating the driver's C codebase to align with modern kernel APIs. This contribution successfully restored Wi-Fi 6 connectivity for devices like the TP-Link AX1800 on more recent Linux distribution versions.
